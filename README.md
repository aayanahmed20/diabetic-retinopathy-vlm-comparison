# Diabetic Retinopathy Grading: Gemini vs. MedGemma vs. RetiZero

A comparative evaluation of three vision-language models on ICDR-graded diabetic
retinopathy severity classification (grades 0-4), scored against ground-truth labels from
the [APTOS 2019 Blindness Detection](https://www.kaggle.com/competitions/aptos2019-blindness-detection)
dataset. Built as a mini research project aiming at an IEEE submission.

## Why this exists

Diabetic retinopathy is retinal blood-vessel damage caused by prolonged high blood sugar,
and it's the leading cause of vision loss among working-age adults worldwide. Screening
relies on grading fundus photographs against the International Clinical Diabetic
Retinopathy (ICDR) severity scale - 0 (no DR) through 4 (proliferative DR) - but grading is
labor-intensive and graders disagree with each other as often as kappa 0.40-0.65.

The question this project asks is whether modern vision-language models can do that grading
automatically, and specifically whether medical pretraining buys anything over a general
model. Three systems, all scored against the same ground truth:

| Model | Type | Access |
|---|---|---|
| [Gemini](https://ai.google.dev/) | Hosted general-purpose multimodal API | API key |
| [MedGemma](https://huggingface.co/google/medgemma-4b-it) | Open-weight medical VLM (Google) | Hugging Face (gated, free) |
| [RetiZero](https://github.com/LooKing9218/RetiZero) | Open retinal foundation model, zero-shot | GitHub + manual weights download |

RetiZero is the interesting one to compare against: it's a CLIP-style model pretrained on
341,896 fundus images across 400+ diseases, and its zero-shot performance beats the average
of 19 ophthalmologists in its own evaluation. But it works by embedding the image against
candidate text labels (similarity scoring), not by writing a digit - so it's being scored
on a mechanically different task than the two generative models. The report treats that
asymmetry explicitly rather than pretending the three are a fair fight.

## What this repo gives you

This repo contains a **complete, ready-to-run pipeline**, not pre-computed results.
`results/predictions.csv`, `results/metrics_summary.json`, `results/summary_table.csv`, and
`results/confusion_matrices.png` are generated by running the notebook. They aren't checked
in, because the numbers have to come from an actual run against your own API/GPU access,
not be invented.

Beyond plain accuracy, the pipeline scores each model with:

- **Quadratic-weighted Cohen's kappa** - the standard metric in the DR-grading literature,
  and literally the Kaggle competition's own scoring metric. It penalizes a Grade 0 -> 4
  error more than a 0 -> 1 error, which plain accuracy can't see.
- **Mean absolute error** in grade steps
- **Bootstrap 95% CI on accuracy** - honest uncertainty bounds, especially important at
  small sample sizes
- **Per-class precision/recall and confusion matrices**

## Getting started

1. Open `notebooks/DR_VLM_Comparison.ipynb` in **Google Colab** (File > Upload notebook, or
   open directly from GitHub via File > Open notebook > GitHub).
2. Runtime > Change runtime type > **GPU** (T4 minimum - MedGemma and RetiZero need it).
3. Add these as **Colab secrets** (key icon in the left sidebar) - never paste them into a cell:
   - Kaggle - **either** `KAGGLE_USERNAME` + `KAGGLE_KEY` (classic) **or** `KAGGLE_API_TOKEN`
     (new `KGAT_...` format): kaggle.com > Account > API > Create New Token
   - `GEMINI_API_KEY` - https://aistudio.google.com/apikey
   - `HF_TOKEN` - https://huggingface.co/settings/tokens, and accept the license at
     https://huggingface.co/google/medgemma-4b-it with the same account
4. Run all cells top to bottom. RetiZero's pretrained weights (~a few hundred MB) download
   automatically from Google Drive via `gdown`.
5. The last cell packages `results/` into a tarball and triggers a browser download.
   Extract it into the repo root.
6. Fill `reports/report_template.md` with the numbers from `results/metrics_summary.json`.

To regenerate the notebook from its source (rather than editing JSON by hand):

```bash
pip install nbformat
python build_notebook.py
```

## Status

The notebook is structurally complete and the RetiZero wiring follows its upstream
`Zeroshot.py` (verified against the actual repo source), but it has not been executed
end-to-end on a GPU in this repo's authoring environment, so first run may surface
runtime-specific issues. Known items to close before publication:

- **Sample size.** Default is `N_PER_GRADE = 2` (10 images), matching the original scoping
  request. That's a pipeline smoke test, not a result - for anything intended for
  submission, raise it to 20-30 per grade (100-150 images) and report the bootstrap CIs.
  One wrong prediction swings 10-image accuracy by 10 points.
- **RetiZero dependency tension.** Its upstream repo pins torch 1.13 / transformers 4.27,
  which would break MedGemma's modern stack. This notebook deliberately runs it on the
  current Colab stack; if you hit a RetiZero-specific error, run its cells in a separate
  runtime and combine the CSVs (the pipeline is built so predictions survive independently).
- **Ground truth caveat.** Published inter-ophthalmologist agreement on ICDR grading is
  kappa 0.40-0.65 - the "ground truth" here is one grader's label, not an infallible
  reference. Say so in the writeup.
- Gemini is a generalist model doing a specialist task the other two were trained for -
  note that asymmetry rather than presenting the comparison as three peers.

## Background: what's being graded

The **ICDR severity scale** grades fundus photographs 0-4:

| Grade | Name | Description |
|---|---|---|
| 0 | No DR | No abnormalities |
| 1 | Mild NPDR | Microaneurysms only |
| 2 | Moderate NPDR | More than microaneurysms, less than severe |
| 3 | Severe NPDR | Extensive hemorrhages / venous beading / IRMA, no neovascularization yet |
| 4 | Proliferative DR (PDR) | Neovascularization and/or vitreous/preretinal hemorrhage |

Diabetic retinopathy is retinal blood vessel damage from prolonged high blood glucose, and
a leading cause of vision loss in working-age adults worldwide. Risk factors include
diabetes duration, poor glycemic control, hypertension, and kidney disease markers. Left
untreated it can progress to diabetic macular edema, vitreous hemorrhage, retinal
detachment, and neovascular glaucoma.
